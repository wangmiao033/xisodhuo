# 《时尚小镇》新手导览 + 第一关 + 第一次装修 V0.1

> 目标：把玩家第一次进入游戏后的 3–6 分钟做成一个完整、连续、可玩的 Vertical Slice。
>
> 风格参考：原《梦想遇见童话》的“角色在场景中 + NPC 对话 + 聚光遮罩 + 逐步解锁”体验，而不是网页式菜单教学。

---

## 0. 开发前置

继续使用：

- Cocos Creator 2.4.10
- JavaScript
- 720×1280 竖屏逻辑坐标（与未来 1080×1920 同为 9:16）
- 现有地图 / MapDataMgr / MapObject / 装修 / Replacement 换装底层
- 本地游客账号和本地存档
- 默认关闭旧服务器、旧渠道 SDK、旧农场玩法

如果 Cursor 本地已有 phase2 / phase3 修改，必须先保留并叠加到当前开发分支，不要回退。

---

# 1. 新手导览总流程

第一次进入游戏：

```
启动
→ 创建/读取本地 UID
→ 读取本地存档
→ 判断 tutorial.step
→ 进入时尚小镇主场景
→ 新手向导出现
→ 小镇导览
→ 接到第一个委托
→ 进入第1关三消
→ 胜利结算
→ 获得金币 + 星星 + 第一件家具
→ 返回家园
→ 放置第一件家具
→ 新手完成
→ 正式进入自由游戏
```

整个流程不要反复打开大量说明面板。

---

# 2. 新手向导角色

临时名称：

**小镇向导 · 桃桃**

正式美术未到位前可以：

- 复用现有 NPC / 角色资源
- 或只使用头像占位
- 不要因为缺正式角色美术阻塞逻辑

职责：

- 负责首轮导览
- 后续功能解锁时可重复出现
- 不要替玩家自动操作

---

# 3. 第一句话

玩家第一次真正进入小镇后：

> 欢迎来到属于你自己的时尚小镇。  
> 从今天开始，这里会一点一点变成你喜欢的样子。

显示方式：

- 场景继续可见
- 底部对话框
- NPC 头像
- “继续”按钮
- 不要做全屏教程说明页

---

# 4. 小镇导览

## Step 1：我的家

镜头移动或聚光到“我的家”。

对话：

> 这里是你的家。  
> 以后可以自由装修房间，收藏喜欢的家具。

要求：

- 建筑/区域高亮
- 其他区域半透明遮罩
- 不强制进入家园
- 2 秒左右即可理解

---

## Step 2：时尚街 / 换装

镜头移到换装区域。

对话：

> 想换个新造型，就来这里看看。  
> 发型、衣服、鞋子和饰品，都可以慢慢收集。

要求：

- 高亮换装入口
- 可以短暂展示角色换装效果
- 不强制进入完整换装 UI

---

## Step 3：收藏馆 / 卡册

对话：

> 在小镇生活中，会遇见很多特别的瞬间。  
> 它们都会被收进你的卡册里。

要求：

- 高亮卡册 / 收藏馆
- 首轮只介绍概念，不教具体操作

---

## Step 4：好友街区

对话：

> 以后还可以拜访朋友的小镇，看看他们的家和穿搭。

要求：

- 入口可以显示“即将开放”
- 首版好友功能未完成也不影响新手流程

---

## Step 5：活动广场

对话：

> 小镇每天都会发生新的事情。  
> 活动、任务和限定奖励都会从这里开始。

要求：

- 不进入活动 UI
- 只做导览

---

## Step 6：闯关入口

对话：

> 想让小镇变得越来越漂亮，需要收集装修资源。  
> 前面正好有人需要帮助，我们去看看吧！

然后进入第一个委托。

---

# 5. 第一个委托

标题：

**春日花店的请求**

NPC：

花店店员 / 临时 NPC

对话：

> 花店准备重新布置橱窗，还差一些新鲜花朵。  
> 可以帮我收集一点吗？

任务目标：

```
鲜花 × 12
```

按钮：

```
开始第1关
```

---

# 6. 第1关

关卡名：

**第1关 · 初到小镇**

基础：

- 8×8
- 6 种棋子
- 20 步
- 不允许开局自动三连
- 相邻交换
- 无效交换回退
- 横/竖三连
- 连锁
- 下落补棋

棋子临时主题：

- 鲜花
- 蝴蝶结
- 手袋
- 鞋子
- 相机
- 咖啡

正式美术后替换，不要用原农场素材。

第一关目标：

```
收集鲜花 × 12
```

顶部需要出现：

- NPC 小头像
- 当前目标
- 剩余步数

不要把主导航塞进三消界面。

---

# 7. 第一关胜利

胜利条件：

收集鲜花达到 12。

奖励：

```
金币 +300
星星 +1
春日花篮 ×1
```

同时：

- 完成 level 1
- maxLevel 至少变成 2
- levelStars[1] 记录
- 保存本地存档

结算文案：

> 做得不错！  
> 现在把刚得到的花篮带回你的新家吧。

主按钮：

**回家布置**

---

# 8. 第一次家园装修

进入家园后：

- 暂时隐藏大部分无关 UI
- 聚光到一个推荐摆放区域
- 底部只展示 1–3 个可放置家具

必须有：

**春日花篮**

对话：

> 试着把刚获得的花篮放进家里吧。

允许：

- 预览
- 移动
- 确认

如果旋转已经稳定，可以开放旋转。

第一步不要让玩家面对几十个家具。

---

# 9. 放置成功

确认放置后：

> 完成啦！  
> 这就是属于你的第一处小小变化。

然后：

> 以后还可以继续闯关、装修、换装、收集卡片，也可以去拜访朋友的小镇。

按钮：

**开始我的小镇生活**

点击后：

```
tutorial.completed = true
tutorial.step = END
```

进入正常游戏状态。


# 16. 失败与容错

如果玩家三消失败：

显示：

> 差一点就成功啦，再试一次吧！

按钮：

- 重新挑战
- 暂不提供付费复活

如果游戏在新手过程中被关闭：

下次启动：

- 读取 tutorial 状态
- 回到最近一个安全步骤
- 不从头重复整段导览

---

# 17. 开发阶段占位

正式切图尚未完成时：

允许：

- 原场景作为底图
- 原角色作为占位
- 纯色 Tutorial 面板
- 临时图标
- 简单粒子

不允许：

- 因缺正式 UI 图而停止逻辑开发
- 再创建一个独立 React/Vite 游戏替代 Cocos

# 18. 验收流程

必须至少手动/自动验证：

### Case 1 首次用户

```
无存档
→ 进入小镇
→ 看到欢迎语
→ 完成 6 个导览点
→ 接任务
→ 第1关
→ 通关
→ +300金币
→ +1星
→ 得春日花篮
→ 回家
→ 放花篮
→ 新手完成
```

### Case 2 中途退出

分别在：

- 导览第3步
- 第1关前
- 第1关后
- 家具未放置前

退出并重启。

必须能继续，而不是乱跳。

### Case 3 已完成新手

重启：

不能再次强制播放新手导览。
